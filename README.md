📊 Gold Price Dashboard 💰
เว็บแอปสำหรับดูราคาทองคำเรียลไทม์ พร้อมเครื่องมือคำนวณกำไร-ขาดทุนจากการซื้อขายทอง

✨ คุณสมบัติ
📈 อัปเดตราคาทองคำ อัตโนมัติจากสมาคมค้าทองคำ
💡 คำนวณกำไร-ขาดทุน จากราคาทองที่ซื้อ
🛒 ช่วยคำนวณราคาซื้อทองของร้านทอง พร้อมค่ากำเหน็จ ค่าเสื่อม และค่าใช้จ่ายเพิ่มเติม
🎨 UI ใช้งานง่าย ด้วย Streamlit
🚀 การใช้งาน
ติดตั้งไลบรารีที่จำเป็น
pip install -r requirements.txt
รันแอป Streamlit
streamlit run your_script.py
เปิดเบราว์เซอร์ไปที่ http://localhost:8501/
